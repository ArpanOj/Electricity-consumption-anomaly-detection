# CU-BEMS raw files (not stored in git: about 700 MB)
Download the 14 CSV files (2018Floor1-7, 2019Floor1-7) from figshare, DOI 10.6084/m9.figshare.11726517
(Pipattanasomporn et al., Scientific Data 2020) and put them in this folder. Notebook 11 turns them into the hourly files in data/cu_bems_hourly/.
Note: the published 2019Floor6.csv stops on 22 October 2019 (see Master Document section 20.14).
